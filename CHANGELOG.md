# Changelog

User-facing changes for Win11 Control Center Pro.

## 2.0.25

- Consolidated system information and quick actions in the Overview workspace.
- Separate workspaces for Windows app packages and classic installed programs.
- Categorised Windows tweaks and privacy controls.
- Analysis-first system cleanup with selectable cleanup categories.
- Activity history and supported registry/configuration snapshots with restore support.
- Close behaviour supports keeping the application in the system tray or exiting completely.
- Separate uninstaller executable.

> Release notes describe the features documented for this version. Availability can vary by Windows configuration.
