# Security

If you believe you have found a security vulnerability in Win11 Control Center Pro, please do not publish exploit details, private data, or instructions for abusing the issue in a public GitHub issue.

Contact the project owner through a private channel associated with the repository and include:

- The affected application version.
- The Windows version and architecture.
- A concise description of the suspected vulnerability and its possible impact.
- Reproduction steps that do not expose personal data or harm another system.

Do not include passwords, access tokens, private keys, personal documents, or unredacted diagnostic logs.

Please allow time for the report to be reviewed before disclosing technical details publicly. No response-time guarantee is implied.
