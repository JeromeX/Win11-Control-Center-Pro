# Features

This page describes the user-facing areas of Win11 Control Center Pro 2.0.25.

## Overview

Review key Windows and hardware details, live CPU and memory indicators, disk and network status, security indicators, and shortcuts to common areas.

## Remove Apps

Review supported AppX/MSIX packages and the selected removal scope before confirming an operation. Package availability and removal options can differ by Windows installation and user context.

## Install Apps

Use the application's catalogue to install supported entries through the available Microsoft Store or WinGet source. Availability depends on the selected source and the PC's configuration.

## Installed Programs

Review classic desktop applications registered with Windows. Open their registered uninstallers and inspect possible leftover files or registry entries. A leftover entry should be reviewed before any manual removal.

## Windows Tweaks

Browse categorised Windows adjustments. Read each description and impact note before applying a setting. A recommendation is guidance, not a requirement for every PC.

## Privacy

Review supported privacy-related options, including selected advertising, diagnostics, app-permission, feedback, and activity-related controls. Exact options depend on Windows version and policy.

## System Cleanup

Analyse cleanup areas before choosing what to remove. Supported categories include temporary files, thumbnails, selected caches, and optional browser data. Selecting cookies, sessions, or history can sign you out of websites or remove local browsing records.

## History & Recovery

Review the application's activity records and registry/configuration snapshots created for supported operations. Restore applies only to values recorded and supported by the application; it is not a full system restore.

## System tray and startup

The close prompt offers the option to keep the application running in the system tray or exit completely. The optional Windows startup setting launches the application for the signed-in user after sign-in.
