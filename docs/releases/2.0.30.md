# Win11 Control Center Pro 2.0.30

**Platform:** Windows 11 x64  
**Release tag:** `2.0.30`  
**Release type:** Feature and maintenance update

## Highlights

### Installed-program updates

- Check available updates through configured WinGet sources, including Microsoft Store packages where a matching source entry is available.
- Check Chocolatey and Scoop packages when those package managers are installed.
- Ask for permission before contacting online package sources.
- Verify package identifiers and providers before enabling update selection.
- Use **Select available** to select verified updates, then review the selection and confirm **Update selected**.
- Highlight only the **Available Version** cell with the red update pulse; other program columns remain static.
- Show scan time, provider status, and update counts in the Installed Programs area and System Status card.

Packages without a supported, verified catalogue entry remain visible but cannot be updated by this workflow. Scoop results use locally cached bucket metadata and may be stale until Scoop buckets are refreshed. This workflow cannot generically update every application that relies exclusively on a proprietary vendor updater.

### System cleanup and background maintenance

- Basic and Deep cleanup profiles, with additional Windows diagnostic and graphics-cache areas in the Deep profile.
- **Select all** and **Select none** actions for cleanup areas.
- A new analysis is required after changing the selection; deletion still requires a separate confirmation.
- Safe background maintenance runs only while the application is inactive, Windows has been idle for at least 10 minutes, and the configured maintenance interval has elapsed.
- Background maintenance is limited to files older than seven days in the current user's temporary folder, DirectX shader cache, and Explorer thumbnail cache.
- Downloads, personal documents, browser cookies, browsing history, saved passwords, and the Recycle Bin are not included in automatic background maintenance.

### Windows tweaks and system information

- Windows Tweaks and Privacy report **Applied** only when the current registry values match the values defined by the selected measure.
- Improved physical GPU detection filters known virtual and remote display adapters.
- Firmware mode detection uses Windows firmware information with a BCD fallback.
- Uptime is calculated from the system tick counter.

### Navigation, system tray, and responsive layout

- Responsive Installed Programs toolbar; action buttons wrap instead of being clipped on narrow windows.
- Program tables retain access to all columns with proportional sizing and horizontal scrolling.
- The red update animation is confined to the Available Version cell, not the entire program row.
- The minimize-to-tray choice is remembered after the first close prompt.
- When Windows startup is enabled, exiting from the tray requires explicit confirmation.
- The branded uninstall mode is integrated into the same `Win11ControlCenter.exe`; the customer payload does not include a second WPF uninstaller or a second .NET runtime.

## Licensing

This build uses the commercial-license-only model described by the 2.0.30 source package:

- One license type: **PRO**.
- Available terms: **1 year**, **2 years**, or **Lifetime**.
- No free trial period or grace period is created.
- Activation is offline, hardware-bound, and verified using RSA-PSS with SHA-256.
- License requests use the `W11REQ2` request format; signed license tokens use `W11C2`.
- The customer application contains only the public verification key. The Admin private signing key remains in the separate encrypted Admin vault.

The Admin License Manager and its private signing vault are not included in the customer installer.

## Requirements

- Windows 11, 64-bit (x64).
- Internet access is needed for online package-source checks and updates.
- The customer application is published self-contained for Windows x64.
