# Sicherheit

Wenn du eine mögliche Sicherheitslücke in Win11 Control Center Pro gefunden hast, veröffentliche bitte keine Exploit-Details, privaten Daten oder Anleitungen zum Ausnutzen des Problems in einem öffentlichen GitHub-Issue.

Kontaktiere den Projektverantwortlichen über einen privaten Kontaktweg, der zum Repository gehört, und gib möglichst folgende Informationen an:

- Betroffene Anwendungsversion.
- Windows-Version und Architektur.
- Kurze Beschreibung der vermuteten Sicherheitslücke und ihrer möglichen Auswirkungen.
- Schritte zur Reproduktion, die keine persönlichen Daten offenlegen und kein fremdes System gefährden.

Füge keine Passwörter, Zugriffstoken, privaten Schlüssel, persönlichen Dokumente oder ungeschwärzten Diagnosedaten bei.

Bitte ermögliche eine Prüfung der Meldung, bevor du technische Details öffentlich machst. Eine feste Antwortzeit wird nicht zugesichert.
