# Support

For questions or issues with Win11 Control Center Pro, use the repository's GitHub Issues page.

When reporting an issue, include:

- Application version (for example, 2.0.25).
- Windows edition and version.
- The workspace or function involved.
- The exact steps that led to the issue.
- The full, non-sensitive error message, if available.

Before attaching screenshots or logs, remove usernames, email addresses, device identifiers, personal folder paths, IP addresses, and other information you do not want to publish.

Do not post passwords, product keys, authentication tokens, private backup files, or unredacted diagnostic data in a public issue.

For security vulnerabilities, follow [Security](SECURITY.md), or contact the project owner privately rather than publishing exploit details in a public issue.
