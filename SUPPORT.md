# Support

For usage questions and ordinary troubleshooting, open a GitHub issue using the appropriate template, provided the repository owner has enabled Issues.

Please include:

- Win11 Control Center Pro version;
- Windows edition and build;
- the workspace and action involved;
- the complete error text;
- relevant log excerpts after removing personal information.

Logs are normally stored under `%LOCALAPPDATA%\Win11ControlCenter\Logs`.

Do not use public issues for credentials, personal data, or suspected security vulnerabilities. See [Security](SECURITY.md).
